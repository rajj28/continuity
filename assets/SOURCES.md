### Why the master is not in the repo

It is 224 MB, which is poor practice in a git repository and unnecessary: it is
freely and permanently available from the Blender Foundation. `make fetch-master`
downloads it and verifies the SHA-256 recorded above, so the pipeline is fully
reproducible without committing the binary. The dialogue list *is* committed
because it is 1.5 KB and is the actual input to the localisation pipeline.

## Generated derivatives

Everything this system produces -- dubbed stems, subtitle files, packages -- is
a derivative of the above and inherits CC BY 3.0. Synthetic voices are produced
by Google Cloud Chirp 3 HD from prebuilt voices; no voice is cloned from a real
performer, and no Instant Custom Voice model is trained on the Sintel cast.

## Test fixtures

`media/fixtures/*.wav` are tones generated by `scripts/make_fixtures.sh` with
ffmpeg. They contain no third-party material and exist only so the QC probes
can be asserted against exactly known utterance boundaries.
